# 🌟 Promise Champion Portfolio App

A **personal portfolio mobile app** built with **React Native (Expo)** and **Tailwind CSS**.  
Created for the **Zuri Mobile Track – Stage 0 Task**, this app showcases my **About**, **Skills**, and **Contact** sections, with full **Light & Dark Theme support**.

---

## 🧑‍💻 Features

- 🌗 **Light / Dark Mode** toggle  
- 🧍‍♂️ **About Section** with profile info  
- 💡 **Skills Section** – organized by Frontend, Backend, Mobile, AI & Tools  
- 📞 **Contact Section** with clickable links (Email, LinkedIn, Portfolio)  
- 💅 Built with **Expo + NativeWind** for a clean, responsive design

## ⚙️ Tech Stack

- **React Native (Expo)**
- **NativeWind (Tailwind CSS for React Native)**
- **React Context API** – Theme Management  
- **@expo/vector-icons** – Icons and UI enhancement  
- **TypeScript Ready**

## 🚀 Getting Started

Follow these steps to set up and run the app locally:

```bash
# Clone the repository
git clone https://github.com/promisedukeac/portfolio-app.git

# Navigate into the folder
cd portfolio-app

# Install dependencies
npm install

# Run the app
npx expo start
```
